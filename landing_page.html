Zero-Risk Safety Architecture

Designed for mission-critical infrastructure where autonomous interventions must maintain mathematical upper bounds.

01

Memory-Locked Core

The Rust Guard Plane uses mlockall with bounded RSS (<100MB). It can never be paged out or become an OOM casualty itself.

[PASS] Immune to swap starvation
02

Mandatory Action TTLs

Every cgroup modification has an ephemeral kernel lease (maximum 300 seconds). If the daemon terminates or drops socket connection, all weights revert instantly.

[PASS] Self-healing kernel lease
03

Protected Whitelist

Display managers (Wayland/X11), SSH daemon (sshd), pipewire, and core systemd slices are strictly untouchable by safety policy.

[PASS] No control plane disconnection

Physical Tsuki Panic

[PASS] Hardware-level fail-safe
